# Tiqany Acc Solo — المحاسب التقني المستقل

**المصدر:** نسخة مستقلة مشتقة من مشروع Tiqany Acc الرئيسي **3.5.49** (13 نوفمبر 2026).

**اسم التطبيق:** `Tiqany Acc Solo` بالإنكليزية، و`المحاسب التقني - مستقل` بالعربية.
**معرّف Android:** `com.tiqany.accounting.solo`.
**إصدار المشروع:** `3.5.49-solo`.

## ما الذي تغير؟

- حُذف مشروع تطبيق المندوب بالكامل (`field_agent`).
- حُذفت واجهات إدارة المندوبين وتعديلهم وربطهم وتفعيل أجهزتهم، وإشعاراتهم وتقاريرهم.
- حُذفت وحدات تشفير ومزامنة LAN/الملفات والاقتران مع تطبيق المندوب، وجسر Android الخاص بها (`NativeLocalSync`).
- أُزيلت فلاتر تقارير الصندوق والأرباح والمبيعات الخاصة بالمندوبين، ومعاملات الصناديق التابعة لهم.
- بقي سجل الصندوق الرئيسي مستقلاً ويحتسب المقبوضات والمدفوعات والفواتير النقدية والمصاريف.
- بقي مركز الإشعارات للمواد التي ينفد مخزونها، مع العدد الأحمر للإشعارات غير المقروءة.
- بقيت المحاسبة والفواتير والسندات والمشتريات والمرتجعات والذمم والجرد والمناقلات والمصاريف والتقارير والطباعة الحرارية 80 مم واللغتان والحماية والنسخ الاحتياطي.
- نسخة Solo مستقلة عن النسخة الكاملة على مستوى Android، ويمكن تثبيتهما جنباً إلى جنب من دون مشاركة قاعدة بيانات أو إعدادات أو ملفات داخلية.

## كيف تصنع APK باستخدام GitHub من الهاتف؟

1. أنشئ مستودعاً **جديداً** وفارغاً باسم `Tiqany-Acc-Solo` (لا ترفع ملفات Solo فوق مستودع الإصدار الرئيسي).
2. فك ضغط ZIP وارفع **محتوياته** إلى جذر المستودع بما فيها المجلد المخفي `.github/workflows`، وليس ملف ZIP نفسه.
3. في GitHub افتح **Actions → Build Tiqany Acc Solo Android APK → Run workflow**.
4. عند نجاح البناء، افتح آخر عملية بناء، وحمّل الملف **Tiqany-Acc-Solo-APK** من قسم Artifacts.
5. فك ضغط Artifact وستجد **Tiqany-Acc-Solo-DEBUG.apk** للاختبار والتثبيت. إن أعددت مفاتيح توقيع Solo، سينتج `Tiqany-Acc-Solo-SIGNED.apk` بدلاً منه.

للتحديثات الدائمة بنفس التوقيع، أضف الأسرار `SOLO_KEYSTORE_BASE64` و`SOLO_STORE_PASSWORD` و`SOLO_KEY_ALIAS` و`SOLO_KEY_PASSWORD` في إعدادات المستودع الجديد. لا تنشر مفتاح التوقيع. استخدم مفتاحاً ثابتاً لكل تحديث، ولا تغيّر معرّف التطبيق.

## بيانات النسخة الأصلية والنسخ الاحتياطي

- لا يتم حذف أو تعديل بيانات التطبيق الأصلي المثبت على الهاتف. النسخة المستقلة تبدأ بقاعدة بيانات منفصلة.
- لا تنتقل البيانات تلقائياً من التطبيق الأصلي إلى Solo. لنقل سجلات محاسبية، صدّر نسخة JSON من الأصل واستعدها داخل Solo باستخدام وسائل التحقق والحماية المتاحة.
- الاستعادة من نسخة إصدار المندوبين **تبقي السجلات المالية الموثّقة** (الفواتير، السندات، المصاريف، الذمم)، وتزيل منها بيانات هوية المندوب وسجل المزامنة وإشعارات المندوبين. احتفظ دائماً بنسخة JSON الأصلية خارج Solo قبل أي استعادة.
- ملفات النسخ التلقائي تحمل بادئة Solo، ومجلد Drive المستهدف (إن فُعّل في تطوير لاحق) يحمل اسماً مختلفاً. النسخ الاحتياطية المحلية ضمن بيانات كل تطبيق معزولة أيضاً.
- نظام التفعيل الموقّع الأصلي **موجود** في نسخة Solo، ويتعامل مع إعدادات وتفعيل مستقلين عن النسخة الرئيسية. لم يُرفق مفتاح إصدار أكواد التفعيل الخاصة بالمالك.

## الاختبارات

فحص `node tests/test_solo.js` وظائف العزل، والصندوق، وتنبيهات المخزون، وصون القيم المالية عند الاستعادة. كما يوجد فحص المحاسبة واختبار التراخيص الموقّعة وفحص صياغة Java وJavaScript. يجري البناء الفعلي للـ APK في GitHub Actions؛ لم يُبنَ أو يُختبر APK على هاتف حقيقي أثناء استخراج هذه النسخة.
