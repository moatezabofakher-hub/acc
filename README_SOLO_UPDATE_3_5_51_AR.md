# تحديث Tiqany Acc Solo 3.5.51

لترقية نسخة Solo 3.5.49، ارفع الملفات المعدلة إلى نفس المسارات في المستودع `moatezabofakher-hub/acc` ولا ترفع ZIP نفسه. لا حاجة لإنشاء مستودع جديد.

التحديث يشمل المواد التجميعية، تسعير الجملة/المركز، تسعير العملاء، زر العملة المصغر (في بطاقة المادة والعملة الافتراضية بالضبط)، وتحسين خلفية خيار الكاميرا. كما يحافظ على تكبير أيقونات الشريط السفلي ويعرض رقم الإصدار المثبت.

لا توجد أي أكواد للمندوبين. يحتوي المشروع على اختبارات JavaScript ووظائف الحسابات، واستُخدم فيه ملف بناء GitHub Actions يهيئ Android SDK من بيئة GitHub.

تأكد من إضافة مجلد `.github/workflows` عند رفع الملفات، ثم شغل GitHub Actions. بلا أسرار تحصل على Debug، ومع أسرار Solo الأربعة تحصل على Release موقعة. نفس مفتاح التوقيع مطلوب لترقية APK المثبت مسبقا.

خُذ نسخة احتياطية من المحاسبة قبل ترقية أي إصدار. ملف APK غير مضمن؛ لم يُختبر تشغيله على هاتف حقيقي.
