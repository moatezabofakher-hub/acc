# تحديث Tiqany Acc Solo — 3.5.51-solo.5 (versionCode 6)

هذه حزمة مستقلة **للمستودع `moatezabofakher-hub/acc` فقط**. لا ترفعها إلى التطبيق الرئيسي ولا إلى مستودع المندوب. لا تنشر مفاتيح التوقيع في GitHub.

## الجديد

- سعر المستهلك للمواد والوحدات الفرعية والمواد التجميعية، إضافة إلى الجملة والمركز.
- إعداد في صفحة إعدادات الفواتير لتحديد سعر البيع الافتراضي.
- بطاقة الحساب: «حسب الإعدادات» أو سعر ثابت (جملة أو مركز أو مستهلك). لا يتغير السعر الثابت عند تغيير الإعداد العام.
- المعاينة وطباعة الفواتير على الطابعة الحرارية/ملف PDF تُظهر رصيد ما قبل الفاتورة والرصيد الحالي بعملة الفاتورة فقط، دون التعديل على البيانات المحاسبية.
- شبكة لاختيار مكونات المادة التجميعية بصور المواد، مع البحث حسب الاسم والتصفية حسب المجموعة. انقر المادة لإضافتها، وانقر مجدداً لزيادة العدد؛ يُمكن تعديل الكمية من القائمة أو حذف المادة.
- تحسين زر اختيار المكونات لمظهر ثلاثي الأبعاد لامع، وتحسين تباين الأزرار ذات الأيقونات المنفردة، والمحافظة على أيقونات الشريط السفلي المكبّرة والموزعة على كامل الشاشة.
- اختبارات إضافية للتسعير، وأرصدة الدولار/الليرة، وشبكة اختيار المكونات؛ يجري تشغيلها تلقائياً في GitHub Actions.

## طريقة التحديث

1. خذ نسخة احتياطية من بيانات Solo من داخل التطبيق.
2. فك ضغط **حزمة ملفات التحديث**، وارفع محتوياتها إلى مستودع `acc` في نفس المسارات، واستبدل الملفات القديمة؛ **لا ترفع ملف ZIP نفسه**. الملفات الجديدة في `tests/` يجب رفعها أيضاً.
3. شغّل GitHub Actions → Build Tiqany Acc Solo Android APK.
4. إذا كانت الأسرار الأربعة موجودة سيصدر ملف `Tiqany-Acc-Solo-SIGNED.apk`، وإلا سيصدر DEBUG.
5. للتثبيت فوق النسخة الحالية دون إزالة بياناتها، استخدم مفتاح توقيع Android ذاته الذي استخدمته النسخة المثبّتة.

**ملاحظة:** الاختبارات البرمجية والتحقق من صياغة JavaScript/Java نجحت. لم يتم بناء APK أو اختباره عملياً على هاتف حقيقي في هذه البيئة. لا تتضمن الحزمة مفاتيح توقيع أو كلمات مرور أو بيانات زبائن.
